# GDPR — Regulation (EU) 2016/679

Full article text of the General Data Protection Regulation, fetched from [gdpr-info.eu](https://gdpr-info.eu/), which organizes the regulation article by article.

Each file `art_NN.md` contains one article's title and full operative text, with a link back to the original source page.

## Known limitation

The list numbering you see on gdpr-info.eu for sub-points within an article (e.g. paragraph (1), point (a), (b), (c)...) is generated by the website's CSS, not present as literal text in the page. Because of this, and because the underlying HTML for nested lists is inconsistently structured across articles, these extracted `.md` files preserve the article's paragraphs/list items as plain bullet lines but do NOT guarantee the exact original (1)/(a)/(b) labels are reproduced. For any citation that depends on an exact sub-point letter/number (e.g. "Article 6(1)(f)"), cross-check against an authoritative source such as [EUR-Lex](https://eur-lex.europa.eu/eli/reg/2016/679/oj) before relying on it.
