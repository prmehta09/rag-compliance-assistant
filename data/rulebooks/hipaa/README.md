# HIPAA — Administrative Simplification Regulations

Full current text of 45 CFR Parts 160, 162, and 164 (the HIPAA Administrative Simplification regulations: general provisions, transaction/code set standards, and privacy/security/breach-notification rules), fetched from the official [eCFR](https://www.ecfr.gov/) API rather than the HHS.gov combined-text PDF, because HHS.gov's site blocked automated downloads (403 Access Denied) while eCFR's API did not.

Unlike the GDPR text, the CFR source preserves the original paragraph/point numbering (e.g. `(a)`, `(1)`, `(i)`) literally as text, so citations here are exact.

Each section/appendix is saved as its own file under `160/`, `162/`, or `164/`, named after its section number (e.g. `164/164_502.md` for § 164.502).
